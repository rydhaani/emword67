# photos

put every picture for the site in this folder.

- upload with **add file → upload files** while you're inside this folder
- then type the file name into `content/list.txt` or `content/letter.txt`
- big phone photos are shrunk automatically a minute after you upload them, and iphone `.heic` photos are turned into `.jpg` (you can keep writing `.heic` in the text files, the site finds the `.jpg`)
